# Devtools marketing swipe file — mobile reader

A static, phone-friendly reader for 72 devtools marketing case studies. Swipe vertically through one complete case card at a time, or use the Previous and Next buttons. The page also includes planning notes and a research archive.

## Deploy

Deploy this repository as a static site on Vercel or Netlify. Use the repository root as the publish directory. No build command, packages or environment variables are needed.

`index.html` is self-contained. The bundled PDFs provide the reader edition and original research for offline use and source traceability.

Text size and your last case are saved only in your browser.
